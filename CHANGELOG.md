## [0.1.0] — не выпущено

Первая публичная версия: портативный SSH-клиент для Windows со встроенным ИИ-агентом.

### Добавлено

- SSH-сессии: аутентификация паролем, приватным ключом и через ssh-agent Windows.
- Проверка ключей хостов по `known_hosts` (TOFU); при несовпадении ключа подключение отклоняется.
- Импорт хостов из `~/.ssh/config`.
- Вкладки терминала на xterm.js: поиск по буферу, переподключение и дублирование сессий.
- ИИ-агент с 16 инструментами: подключение, команды, отправка клавиш, чтение экрана, хосты, темы
  и настройки.
- Чаты агента: история, группы и архив; подтверждение команд по умолчанию и режим полного
  доступа с явным предупреждением.
- Тёмная и светлая темы, масштабирование интерфейса, русский и английский языки.
- Портативность: данные в `data/` рядом с exe, путь переопределяется через `CONDUIT_DATA_DIR`.
- Иконка приложения и единственный экземпляр: повторный запуск фокусирует открытое окно.
- Шифрование секретов (пароли, парольные фразы ключей, API-ключ) через Windows DPAPI с миграцией
  уже сохранённых данных.
- Подтверждение неизвестного ключа хоста с отпечатком и явное обновление записи при смене ключа.
- Экран «О программе» с версией, путями данных и логов и копированием диагностики.
- Логи с ротацией в `data/logs/conduit.log` без секретов, содержимого терминала и переписки.
- Предупреждение о передаче сообщений и вывода терминала в LLM перед первым сообщением агенту.
- Длинные чаты открываются быстрее: показываются последние 800 записей, полная история сохраняется.

### Исправлено

- Повреждённые файлы настроек и чатов больше не мешают запуску: они изолируются с резервной
  копией, приложение стартует с настройками по умолчанию.
- Устранены падения на пустых и некорректных данных сессий и чатов.
- Повторный запуск приложения больше не создаёт второе окно.
