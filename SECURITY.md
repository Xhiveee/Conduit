# Безопасность

## Поддерживаемые версии

| Версия | Поддержка |
| --- | --- |
| 0.1.x | Исправления безопасности выходят патчами в этой ветке |
| старее | Не поддерживается |

0.1.0 — первая публичная версия, проект в статусе pre-release.

## Как сообщить об уязвимости

Не создавайте публичный issue. Отправьте приватный отчёт через GitHub Security Advisories:

https://github.com/xhiveee/Conduit/security/advisories/new

В отчёте укажите версию Conduit, версию Windows, шаги воспроизведения, влияние и ожидаемое
поведение. Удалите из логов и скриншотов пароли, приватные ключи и API-ключи.

Что происходит дальше:

- подтверждаем получение в течение 7 дней;
- согласуем срок исправления и публикации — обычно 30–90 дней, для критичных случаев быстрее;
- исправление выходит в патче 0.1.x;
- по желанию указываем автора отчёта в release notes.

Программы bug bounty нет.

## Что входит в область рассмотрения

- SSH-подсистема: аутентификация (пароль, приватный ключ, ssh-agent Windows), PTY, буфер
  терминала, переподключение и дублирование сессий.
- Проверка ключей хостов (`known_hosts`, TOFU) и обработка несовпадения ключа.
- Хранение секретов на диске: пароли, парольные фразы ключей и API-ключ в `data/conduit.json`.
- Выполнение команд агентом: подтверждения, режим полного доступа, границы инструментов.
- Передача данных в ИИ-агента: что и когда уходит на настроенный endpoint.
- WebView2-обвязка: отображение Markdown и вывода терминала, навигация, доступ к локальным файлам.
- Файлы данных приложения: `data/conduit.json`, `data/chats/*.json`, `data/known_hosts`.

## Что не входит в область рассмотрения

- Предупреждения SmartScreen и отсутствие подписи кода: сборка 0.1.x не подписана, это известное
  ограничение.
- Отсутствие шифрования секретов в `data/` (план — DPAPI): известное ограничение 0.1.x. Доступ к
  файлам под вашей учётной записью Windows уязвимостью не считается.
- Сторонние сервисы и OpenAI-совместимый endpoint, который вы настроили сами.
- Уязвимости WebView2 Runtime и Windows — их нужно сообщать в Microsoft.
- Локальная атака, требующая доступа к файлам или процессу приложения.
- Социальная инженерия и фишинг.

## Данные и конфиденциальность

- Данные лежат рядом с exe в `data/` или в каталоге из `CONDUIT_DATA_DIR`: `conduit.json` с
  хостами, настройками и секретами, `known_hosts`, `chats/*.json`, профиль WebView2.
- Файлы записываются без шифрования; шифрованное хранение секретов запланировано на 0.1.x.
- Телеметрии нет. Сеть используется только для SSH-подключений и запросов к настроенному API
  агента.
- Агент отправляет на настроенный endpoint запрос пользователя, историю чата и тот вывод
  терминала, который читает. Endpoint выбираете вы; политика обработки данных на стороне сервиса —
  его ответственность. Не подключайте агента к недоверенным endpoint'ам и не давайте ему полный
  доступ к хостам, где это недопустимо.
